Arquitectura de software

Estilo: monolito modular en Django (patrón Modelo-Vista-Plantilla), con páginas renderizadas en el servidor y acciones AJAX que devuelven HTML ya renderizado. No hay SPA, ni build de JavaScript, ni API REST. Cada proceso de negocio es una app de Django, y common.utils es la base que todas usan y que no importa nada de negocio.

Decisiones de arquitectura y el atributo de calidad que protegen:

DecisiónAtributo ISO 25010
El estado de una orden se calcula desde las fechas de cada etapa, nunca se guarda, y se valida en tres capas (métodos, clean()/save() y 10 CheckConstraint)Fiabilidad (integridad)
El admin y las rutas sin permiso responden 404, nunca 403, para no confirmar que existenSeguridad
Los límites de intentos pasan todos por RateLimit, que falla cerrado si Redis caeSeguridad y fiabilidad
La PII va cifrada en la base (Fernet) y los respaldos van cifradosSeguridad (confidencialidad)
Un certificado son tres archivos con dos huellas cada uno; el registro va sellado con Ed25519Seguridad (no repudio)
Cada petición corre en una transacción (ATOMIC_REQUESTS); nada que salga a la red bloquea esa transacciónFiabilidad
El servicio de certificación (code_gen/services) es un paquete con un módulo por responsabilidadMantenibilidad
